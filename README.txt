    AUDIO-DATEIEN (OPTIONAL)
═══════════════════════════════════════════════

Picture Goose funktioniert OHNE Audio-Dateien!

Falls du Sound-Effekte möchtest, lege MP3-Dateien hier ab:

📁 ~/.picture-goose/materials/audio/

Benötigte Dateien:
- start.mp3    : Programmstart
- failed.mp3   : Fehler
- good.mp3     : Erfolg
- accept.mp3   : Einstellungen akzeptiert
- default.mp3  : Einstellungen abgelehnt
- end.mp3      : Programm beendet

🔊 Audio-Player (bereits installiert):
- mpg123

Alternative Player (falls gewünscht):
sudo apt install ffmpeg
sudo apt install sox
