Picture Goose funktioniert OHNE Icon-Dateien!

Falls du eigene Icons möchtest, lege PNG-Dateien hier ab:

📁 ~/.picture-goose/materials/pictures/

Benötigte Dateien (empfohlen 128x128 Pixel):
- icon.png    : Picture Goose Logo
- logo.png    : Change Goose Logo
- failed.png  : Fehler-Icon
- warning.png : Warnungs-Icon

Tipp: Erstelle quadratische Icons für bestes Ergebnis!
